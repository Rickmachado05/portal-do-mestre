# Auxiliar do Mestre — referência da v29.15.30.25

Esta foi a primeira integração do auxiliar ao botão Multiplayer, voltada à instalação de desenvolvimento. Para outros mestres, o caminho recomendado agora é o kit compacto distribuído pelo próprio site.

- **Guia atualizado:** [GUIA_HOSPEDAGEM_PUBLICA_WINDOWS.md](GUIA_HOSPEDAGEM_PUBLICA_WINDOWS.md)
- **Tutorial no Portal:** https://portal-do-mestre.vercel.app/como-hospedar.html
- **Download direto:** https://portal-do-mestre.vercel.app/downloads/auxiliar-do-mestre-windows.zip

O servidor de sessão continua sendo executado no computador do mestre. Os jogadores entram apenas pelo link de convite, sem instalações. O kit contém os scripts do servidor, mas Node.js e cloudflared devem ser obtidos das fontes oficiais.
